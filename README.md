# GOLD ONE — Premium Automotive Landing Page

## Structure
- `index.html` — single-page semantic structure
- `css/style.css` — design system, responsive layout, effects
- `js/script.js` — navigation, motion, counters, comparison slider, lightbox
- `images/` — add your real photography here

## Image map
Add/replace these files:
- `logo.png` — GOLD ONE logo
- `exterior.jpg` — main hero/exterior vehicle image
- `interior.jpg` — immersive interior image
- `car-01.jpg` — about/feature vehicle image
- `service-01.jpg` — services section image
- `before.jpg` — before image for comparison
- `after.jpg` — after image for comparison
- `gallery-01.jpg` through `gallery-06.jpg` — gallery
- `cta.jpg` — final CTA background

You can add more gallery images by copying a `.gallery-card` block in `index.html`.

## Business details to edit
Search `EDIT:` in `index.html`. Replace:
- statistics
- phone
- WhatsApp number
- email
- location
- opening hours
- social links
- service wording/pricing if desired

## Run
Open `index.html` directly in a browser, or serve the folder with any simple local server.

GSAP and ScrollTrigger are loaded from jsDelivr. If you need a fully offline build, download those libraries locally and change the two script tags.
